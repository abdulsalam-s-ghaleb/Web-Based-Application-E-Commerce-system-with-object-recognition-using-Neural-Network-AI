

# Sistema de comercio electrónico (E-Commerce) basado en web con reconocimiento de objetos usando redes neuronales (IA)
Proyecto de fin de carrera: Sistema de comercio electrónico con reconocimiento de objetos usando redes neuronales (IA) desarrollado con Python, Django, JavaScript, MySQL, HTML, CSS, Bootstrap. El sistema permite a los usuarios registrarse e iniciar sesión en la plataforma, así como buscar productos escribiendo o subiendo una imagen en la barra de búsqueda del sitio web. Además, los vendedores pueden acceder al sistema para agregar nuevos productos, editarlos y eliminarlos mediante un pequeño panel de control.
